# 모여 · Community Board

커뮤니티 디자인 시안과 운영자의 음악 노트입니다.

사이트: https://mtljm.github.io/community-board/
음악 목록 바로가기: https://mtljm.github.io/community-board/#music

## 음악 등록·저장

음악 파일 대신 곡명, 아티스트, 앨범, 발매 연도, 감상 링크와 코멘트를 등록합니다.

1. 상단 **음악 리스트 → 음악 등록**을 누릅니다.
2. 곡명·아티스트(필수)와 선택 정보를 입력합니다.
3. **GitHub에서 등록 완료하기**로 이동합니다.
4. `mtljm` 계정으로 로그인하고 **Create 또는 Submit new issue**를 누릅니다. 이 단계 전에는 저장되지 않습니다.
5. 사이트로 돌아와 **목록 새로고침**을 누릅니다.

저장은 공개 저장소의 GitHub Issues를 이용합니다. PC·모바일에서 같은 자료를 조회하며, 등록 정보와 댓글은 공개됩니다. 사이트에 비밀번호나 토큰을 입력할 필요가 없습니다. 인증·마지막 제출은 GitHub에서 수행합니다. 별도 유료 서버나 외부 패키지를 사용하지 않습니다.

- 운영자 `mtljm`이 작성한 음악 형식의 이슈만 사이트에 표시합니다. PR·일반 이슈·다른 사용자의 이슈는 제외합니다.
- 각 곡의 **댓글 · 수정** 링크에서 본문을 수정하거나 댓글을 남깁니다. 수정할 때 `### 곡명` 등의 항목 제목과 식별 주석을 유지하세요.
- 이슈를 닫으면 **보관한 음악**, 다시 열면 **등록된 음악**에 표시됩니다.
- 코멘트는 600자 이내, 감상 링크는 HTTPS를 지원합니다. 파일은 업로드하지 않습니다.
- 한 번에 이슈 100개를 조회하고 **이전 등록 더 불러오기**로 이어서 조회합니다. 검색은 불러온 음악을 대상으로 합니다.
- 비로그인 공개 API 조회 한도나 네트워크 오류가 나면 안내를 표시하고 기존 목록을 유지합니다. GitHub 원문에서도 목록을 확인할 수 있습니다.

`music-model.js`는 입력 검증·GitHub 등록 URL·이슈 파싱·조회, `music.js`는 목록과 등록 화면을 담당합니다. `.github/ISSUE_TEMPLATE/music.md`를 통해 GitHub에서 직접 등록해도 표시됩니다.

## 게시판 시안

목록 필터·검색·정렬·페이지 이동, 글 상세·댓글·좋아요·글쓰기 미리보기를 제공합니다. **기존 게시판 글과 댓글은 메모리에만 존재해 새로고침 시 초기화됩니다.** 음악 노트의 실제 저장 기능과 구분됩니다.

## 실행·검증

Node.js 24에서 `npm start` 후 http://127.0.0.1:8808 접속.
`npm run check`로 JS 문법, `npm test`로 음악 저장 형식·검증·조회 처리를 검사합니다.

## 배포

GitHub Pages가 공개 저장소의 `main` 브랜치 루트(`/`)를 배포합니다. HTML·CSS·JS를 main에 반영하면 다시 배포됩니다. 인증정보는 저장소에 기록하지 않습니다.
