# 모여 · Community Board

디시인사이드의 목록 중심 게시판 구조를 참고한 독립 커뮤니티 디자인 시안입니다. 상표·로고·콘텐츠를 복제하지 않았습니다.

디자인 시안: https://mtljm.github.io/community-board/

## GitHub Pages

공개 저장소의 `main` 브랜치 루트(`/`)에서 배포합니다. `index.html`, `style.css`, `app.js` 수정 후 main에 push하면 페이지가 다시 배포됩니다. 별도 유료 서버나 API를 사용하지 않습니다.

## 실행

Node.js 24에서 `npm start` 후 http://127.0.0.1:8808 접속. 외부 패키지 설치가 필요 없습니다.

## 포함

- 반응형 게시판 목록, 분류·인기글·공지 필터, 검색·정렬·페이지 이동
- 글 상세, 댓글·좋아요 체험, 글쓰기 미리보기
- 모든 예시와 입력은 메모리에만 존재하고 새로고침 시 초기화

실제 인증, 비밀번호, 서버 저장, 파일 업로드는 구현하지 않았습니다. 실제 개인정보나 비밀번호를 입력하지 마세요. 주제와 브랜드 이름은 추후 변경할 수 있습니다.

GitHub Pages에는 저장소 루트의 정적 HTML/CSS/JS를 그대로 배포할 수 있습니다. 공개 게시판 운영에는 별도 백엔드·인증·신고/관리 기능을 추가해야 합니다.
